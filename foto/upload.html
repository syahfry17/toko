UD. BILAL · PERCOBAAN v2

Foto ke Google Drive

Uji satu foto dahulu. Data produk dan halaman toko tidak diubah.

URL sudah diisi. Tekan Cek sambungan setelah Apps Script diperbarui.

1. Sambungkan Apps Script

Gunakan deployment proyek percobaan. Jangan masukkan URL script dari pihak lain.

2. Login admin

Login admin aktif untuk percobaan ini.

Login dikirim langsung ke Firebase. Password tidak dikirim ke Apps Script dan tidak disimpan di halaman ini.

3. Pilih dan upload foto

Otomatis diperkecil ke JPEG, sisi terpanjang maksimal 600 piksel dan ukuran maksimal 200 KB. Gunakan foto produk yang boleh dilihat publik.

4. Baca kembali dari Drive

Buka tampilan foto di tab baru

Untuk pengujian pengunjung: buka tautan foto di tab samaran. Foto harus tetap terlihat tanpa login Google. Ini tampilan melalui Apps Script, bukan URL gambar langsung untuk tag img.
