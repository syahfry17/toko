Salin produk UD BILAL

Masuk dengan akun admin Firebase lama untuk membaca produk, foto, dan modal. Data akan disiapkan di HP sebagai SQL untuk proyek Supabase data-sembako.

Salin ke Supabase

Untuk setiap bagian, salin SQL lalu tempel ke SQL Editor → New query di proyek data-sembako dan tekan Run. SQL berisi harga modal. Simpan hanya di dashboard pribadimu.

Setelah semua bagian berhasil, muat ulang katalog uji dan cocokkan jumlah produk. Jika terjadi kesalahan, catat pesan error tanpa menyalin isi SQL.
